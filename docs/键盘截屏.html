你说的“键盘截屏”，一般有几种方法，我给你整理一下：
🖼 方法一：PrtSc（Print Screen）键
全屏截取 → 按下 PrtSc（有的键上写成 Print Screen、PrtScn、PrtSc SysRq）。
截图会被保存到 剪贴板，然后你可以直接 Ctrl + V 粘贴到 画图、Word、微信、QQ 里。
🖼 方法二：Alt + PrtSc
只截取 当前窗口，而不是整个屏幕。
也会进入剪贴板，需要粘贴出来保存。
🖼 方法三：Win + Shift + S（推荐 Win10/11）
会调出 截图工具栏，支持：
矩形截图
自由形状截图
窗口截图
全屏截图
截好图后自动保存到剪贴板，右下角会弹出一个小缩略图，可以点击保存。
🖼 方法四：Win + PrtSc
截取全屏，并且自动保存到：
图片 → 屏幕截图 文件夹里。
🖼 方法五：Fn 键配合（部分笔记本）
有些笔记本的 PrtSc 需要和 Fn 组合使用，比如 Fn + PrtSc。
有的甚至是 Fn + Win + PrtSc。
