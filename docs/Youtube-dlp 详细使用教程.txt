yt-dlp subs readme


--list-subs：列出可下載的所有字幕
--write-sub：儲存字幕
--write-auto-sub: 儲存自動翻譯的字幕，限 youtube 可以使用
--embed-sub：將字幕合併至影片中，需搭配 –write-sub 參數使用
--all-subs：下載所有字幕
--sub-format：下載的字幕格式，如果原影片沒有指定的字幕格式會去下載其他格式的字幕
--sub-lang：選擇要下載的字幕語言，用逗號分隔，例如：zh_TW,ja
--convert-subs：將下載的字幕轉換成其他格式，目前支援 srt|ass|vtt|lrc

youtube-dl --list-subs https://www.youtube.com/watch?v=AJYsA1jXf60

下載影片與字幕
如果我要下載繁中以及英文的字幕，並另存成 .srt 格式
youtube-dl --sub-lang zh-Hant,en --write-sub --convert-subs srt https://www.youtube.com/watch?v=AJYsA1jXf60

只下載字幕
可以加 --skip-download 跳過下載影片
youtube-dl --sub-lang zh-Hant,en --write-sub --convert-subs srt --skip-download https://www.youtube.com/watch?v=AJYsA1jXf60

下載自動翻譯字幕
下面指令為下載自動翻譯的繁體中文字幕
youtube-dl --write-auto-sub --sub-lang zh-Hant https://www.youtube.com/watch?v=R_BlrlAcOoQ

但是，对我们来说，可没这么简单，因为我们必须科学上网才能访问youtube，所以要告诉yt-dlp，下载时请使用代理服务器来连接。命令如下：

yt-dlp --proxy socks5://127.0.0.1:1080/ https://youtu.be/JlkPChcoHOg
这行命令必须在你的yt-dlp文件夹里执行。

1　在yt-dlp 目录下cd windows powershell
 2.  .\yt-dlp https..........＝１１字节保留 “＆。。。。”＝ＤＥＬ

只下载1080P的视频
yt-dlp --proxy socks5://127.0.0.1:1080/ -f "bv[height=1080]+ba/b" https://youtu.be/JlkPChcoHOg
.\yt-dlp -f "bv[height=1080]+ba/b" https://youtu.be/JlkPChcoHOg
说明：参数-f是说，我对format格式有要求，我要bv，就是best video，同时高度为1080的，也就是我们常说的1080P。音频要ba，就是best audio的。如果找不到满足这些条件的组合，那么就下载一个默认最好的，/b，就是/best的意思。
________________________________________
下载字幕
   yt-dlp --proxy socks5://127.0.0.1:1080/ --write-auto-sub --write-subs --sub-langs en.* -f "bv[height=1080]+ba/b" https://youtu.be/JlkPChcoHOg
.\yt-dlp --write-auto-sub --write-subs --sub-langs cn.* -f "bv[height=1080]+ba/b" https://youtu.be/JlkPChcoHOg
.\yt-dlp --write-auto-sub --write-subs --embed-sub --sub-langs zh-Hant -f "bv[height=1080]+ba/b" https://www.youtube.com/watch?v=nbqlMSgoq_g
.\yt-dlp --write-auto-sub --write-subs --embed-sub --sub-langs zh-Hans -f "bv[height=1080]+ba/b"
            #zh-Hant=hans 是 汉字简体 han simple 缩写hans
            hant 是 汉字繁体(传统体) han traditional 缩写 hant
说明：又加了两条参数，一个是–write-subs，就是下载字幕。如果上传视频的人也做了字幕上传，它就能被下载回来。
我告诉yt-dlp只下载字幕语言是en开头的，即各种英文字幕。写成en.*，是因为人们上传字幕时，要求写语言属性，有的人会直接写en，有的会写en-US，有的写en-UK，为了保险，我把en开头的都下载回来。
另一个参数–write-auto-sub，是说下载youtube自动生成的字幕。当没有可供下载的字幕时，youtube会自动配上听写出来的字幕，虽然不完美，但准确率还是可以接受的，尤其是英文字幕。

下载最高音质
  yt-dlp，可以直接在电脑终端（PowerShell）里输入以下进阶命令。
方案 A：下载 320k MP3（兼容性最好，适合车载或手机）
	这条命令会自动寻找最高音质的音源，并将其转换为 320k 的 MP3。
	Bash
	yt-dlp -x --audio-format mp3 --audio-quality 0 --embed-thumbnail --add-metadata "URL"
	-x: 仅提取音频。
	--audio-quality 0: 强制执行最高比特率（VBR 模式下的最高质量，约 320kbps）。
	--embed-thumbnail: 重点推荐！ 这会将歌曲封面封入文件，在手机播放器上能看到漂亮的专辑图。
	--add-metadata: 将歌手、歌名信息写入文件标签。
方案 B：下载高质量 FLAC（无损格式）
	如果你是发烧友，追求音质且不在乎手机存储空间：
	Bash
	yt-dlp -x --audio-format flac "URL"
-----------------------
批量下载整个歌单
	你不需要一首一首下。如果你在 YouTube 上把自己喜欢的歌存在一个 Playlist（歌单） 里，直接把歌单链接丢给它：
	Bash
	yt-dlp -x --audio-format mp3 -o "%(title)s.%(ext)s" "歌单的URL"
	它会排队把整张专辑全部抓下来。
	Bash
例 ：.\yt-dlp -ix -N 5 --continue --audio-format mp3 --embed-thumbnail -o "%(playlist_index)s - %(title)s.%(ext)s" "你的歌单URL"
 **参数深度拆解**
 -x (or --extract-audio): 		 核心指令。告诉它：“我不要视频，只要音频。”
 --audio-format mp3: 强制转换为 MP3。（注：YouTube 原始音频通常是 m4a 或 webm，这一步需要你电脑里装有 ffmpeg 才能转换成功）。
 -o "%(title)s.%(ext)s": 命名规则。
%(title)s：视频标题。
%(ext)s：后缀名。
如果你想保留歌单里的顺序，建议改成 -o "%(playlist_index)s - %(title)s.%(ext)s"，这样下载下来文件名开头就是 01, 02...
如果你想一次性搞定整个曲库，可以考虑加这几个参数：

功能	参数	说明
断点续传	--continue	如果下载一半断网了，下次运行会从断掉的地方开始。
多线程加速	-N 5	同时开启 5 个线程下载，速度起飞。
嵌入封面	--embed-thumbnail	把视频封面直接变成 MP3 的专辑封面。
忽略错误	-i	如果歌单里某首歌因为版权被删了，它会跳过继续下后面的，而不是直接崩溃。
-------------------------------
注意事项
私有歌单：如果你下载的是你自己的“私有（Private）”歌单，yt-dlp 抓不到。你需要加 --cookies-from-browser chrome（或其他浏览器名）来借用你的登录状态。
网速/版权：部分地区可能需要挂代理，命令结尾可以加 --proxy "http://127.0.0.1:端口号"。

使用说明与避坑指南：
准备工作：
确保你的电脑里有 ffmpeg.exe。因为 yt-dlp 提取音频并封入封面必须要用到它。如果没有它，脚本会报错。
你可以把 yt-dlp.exe、ffmpeg.exe 和这个 DownloadMusic.bat 放在同一个文件夹里。
关于音质：
脚本中使用了 --audio-quality 0。这是 MP3 的 V0 级别（最高质量），非常适合在手机上播放，音质已经无限接近 CD。
关于封面图：
我加入了 --embed-thumbnail 参数。下载完成后，你把文件传到手机里， 播放器会自动显示高清的专辑封面。
解决 403 报错：
脚本开头加入了 yt-dlp -U（自动更新），这是解决 403 问题的“神药”，因为 YouTube 经常更改反爬虫策略，保持工具最新版本至关重要。
下一步建议：
下载完后，你可以直接通过 USB 数据线将手机连接到电脑，把音乐文件拖进手机的 Music 文件夹里。
